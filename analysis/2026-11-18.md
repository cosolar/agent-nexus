## 📊 趋势判断

1. **工具链层是这两周唯一的「超额收益」来源** — 框架层（DSH +4.4%、Matt Pocock Skills +4.8%）增速已经回落到个位数，而工具链层普遍 70%—170%。**存量框架在吃规模，增量注意力在买「体验差」。**

2. **企业级 Agent 从「平台」变成「货架」** — IBM 与微软直接给 6000+ 预置 Agent，意味着企业不再从零编排，而是挑现成的。**这对开源 Agent 框架是压力：要么被集成进货架，要么被绕开。**

3. **编排规模跨过千级门槛** — Fable 5.2 的千级调度 + Agent Substrate 的 <500ms 会话恢复，把「多 Agent」从演示推进到可运营。**下一个瓶颈不再是能不能编排，而是编排完谁负责。**

4. **推理基础设施完成「标准化收尾」** — llm-d 1.0 把 KV 命中率翻倍，llama.cpp 1.0 转正，OpenRL 把后训练搬进 K8s。**推理层正在从「各家自研」变成「标准件」，差异化往上游（数据、后训练）和下游（场景）转移。**

5. **开放权重的竞争从「参数」转向「榜单可信度」** — Kimi 拿下 AA 中国第一，而上一期我们提醒过「评测滞后于发布」。**这次是榜单追上了模型，但只追上一个。** 其余 10 月密集发布的模型仍缺独立横评。

## ⚠️ 三个警惕信号

1. **「全员上涨」本身是风险信号** — 286 个项目里 281 个在涨，这种普涨通常出现在注意力总量扩张期，而非价值分化期。**等普涨结束，才会知道谁在裸泳。**

2. **企业货架化会挤压开源中间层** — 6000+ 预置 Agent 意味着企业可以直接跳过「选框架」这一步。**开源框架如果不能证明「货架上的 Agent 也跑在我上面」，就会被降级为 SDK。**

3. **千级编排的授权模型还没跟上** — 上期说「主动与越权只隔一层授权」，这期规模直接放大到千级。**一个 Agent 越权是事故，一千个 Agent 同时越权是系统性风险，而当前的授权粒度还停留在单 Agent。**
